# Big Data Labs

Лабораторные работы по дисциплине «Большие данные», 1.1–3.2.

- **chapter_1_2**: ex1.py, ex2.py, ex3.py, ex21.py, ex22.py, ex23.py и исходные таблицы.
- **chapter_3**: ex31.py (Streamlit), ex32.py (Gradio) и таблицы для самостоятельных заданий.

Установить зависимости: `pip install -r requirements.txt`.

Исходный `FinCond.xlsx` для совместимости с GitHub подготовлен как `FinCond.csv` (те же столбцы «Х1», «Х2» и «Y»). Код Python читает CSV.

Для запуска ex1.py и ex2.py нужен исходный большой `Customers.csv`, который можно скачать из учебных материалов:
https://disk.yandex.ru/d/SKOuU856U8TJUw

Положите `Customers.csv` в папку `chapter_1_2` перед запуском этих двух работ. Архив со всеми исходными данными сохранён в чате.

Streamlit: `streamlit run chapter_3/ex31.py`.
Gradio: `python chapter_3/ex32.py`.

Исходный файл Rural_prices.csv получен из открытого учебного репозитория: https://github.com/Alenushka2013/Python_Data_Science
